# KGE for Explicit food recommendation - research project

Hummus data from the source https://gitlab.com/felix134/connected-recipe-data-set/tree/master/data should be stored in the folder data/

- `data/` stores source data
- `ontology/` defines the graph vocabulary and shapes
- `src/` contains the data, graph, and recommendation code
- `src/data_ingestion/` prepares and validates recipe data
- `src/kg/` queries and validates graph relationships
- `src/recommenders/` trains, ranks, and evaluates recommendation models
- `results/` stores model outputs and evaluation results
